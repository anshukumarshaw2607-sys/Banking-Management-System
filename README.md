# Banking Management System

## Project Overview
The Banking Management System is a console-based Java application developed using Java, JDBC, and MySQL. It provides basic banking functionalities and allows users to manage bank account information through database operations.

This project demonstrates practical implementation of JDBC connectivity, SQL queries, and fundamental Object-Oriented Programming concepts.

## Features
- Create and manage bank accounts
- Deposit money
- Withdraw money
- Check account balance
- View account details
- Store and retrieve banking information using MySQL
- Perform database operations using JDBC

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- MySQL
- IntelliJ IDEA

## Concepts Implemented
- Basic Object-Oriented Programming
- Classes and Objects
- Methods
- Encapsulation (where implemented)
- JDBC database connectivity
- SQL queries
- Exception Handling

## Database Setup
1. Install MySQL.
2. Create a database for the banking application.
3. Execute the SQL table creation queries.
4. Configure your database URL, username, and password in the Java application.
5. Add the MySQL JDBC driver to your project.

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database connection.
4. Add the MySQL JDBC driver.
5. Run the main Java class.
6. Follow the console menu to perform banking operations.
